# MicrobeTrace Auspice v2 export: Nextstrain review packet

This packet is designed for the MicrobeTrace project lead to share through the existing Nextstrain relationship before release. It contains synthetic data only.

## Examples

- `examples/microbetrace-auspice-minimal.json`: a two-tip divergence-only tree.
- `examples/microbetrace-auspice-rich.json`: scalar traits, colorings, partial tip geography, and a bootstrap branch label.

## Reproduction

1. Open a synthetic dataset in MicrobeTrace and switch to **Phylogenetic Tree**.
2. Select **Export Screen** > **Auspice JSON** > **Save Auspice JSON**.
3. Run `augur validate export-v2 <downloaded-file.json>`.
4. Drag the file onto [auspice.us](https://auspice.us) and open the same directory with `auspice view <directory>`.
5. Rotate and flip a branch before export, then confirm the visible topology and tip order match in Auspice. Also confirm divergence, colorings and filters, mapped tips, and bootstrap labels, with no dataset-processing browser-console errors.

## Compatibility evidence

- Official schema snapshot: pinned to Nextstrain Augur commit `0d287496eed3816f94d674f5a08201273f479487` in `src/app/helperClasses/testData/`.
- Automated schema check: a rich dataset generated by `buildAuspiceV2Dataset` is validated against that snapshot in `auspiceExporter.spec.ts`.
- Official Augur validation: Augur 34.0.0 on 2026-09-22. `augur validate export-v2` succeeded for both examples. The minimal example produced only the expected `No colourings were provided` warning; the rich example succeeded without warnings.
- Browser validation: on 2026-09-22, the rich example rendered its tree, divergence, colorings, filters, map, and bootstrap label in auspice.us 0.15.0 / Auspice 3.0.0 without console errors.
- Rotation validation: on 2026-09-23, a rotated 30-tip synthetic tree retained the same top-to-bottom rendered tip order in MicrobeTrace and auspice.us 0.15.0 / Auspice 3.0.0, including the rotated sibling pair.
- Local-view validation: `auspice view` 3.0.0 discovered both examples and rendered the rich example. Its server returned an optional `root-sequence` sidecar 404 because root sequences are deliberately omitted; no dataset-processing or rendering error occurred.

## Deliberate omissions

The exporter does not include raw sequences, mutations, root sequences, genome annotations, entropy or frequency data, ancestral date or geographic inference, or original Auspice metadata which MicrobeTrace cannot retain semantically. Every export includes divergence. A complete, valid `num_date` tree from an imported Auspice dataset or explicitly annotated dated Newick is preserved without inference, including source date reversals; other datasets remain divergence-only.

## Compatibility questions for Nextstrain

- Is a per-tip synthetic `microbetrace_location` geo resolution the preferred representation when only resolved tip coordinates are available?
- Are scalar ISO date strings with a `temporal` coloring, without `num_date`, expected to remain supported for divergence-only trees?
- Is the optional `root-sequence` sidecar 404 produced by `auspice view` expected for main JSON files which deliberately omit root sequences?
- Does Nextstrain recommend any additional reserved trait names beyond the schema-defined node attributes and `none`?
- Are there preferred semantics for displaying bootstrap percentages which MicrobeTrace stores as branch labels rather than confidence intervals?
