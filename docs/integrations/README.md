# Integration Docs

This folder contains documentation for external integration points.

- `partner-embed-integration.md`: partner embed handoff and integration guidance.
- `auspice-export.md`: exporting the current MicrobeTrace phylogenetic tree for Auspice.
- `auspice-export-nextstrain-review.md`: synthetic compatibility packet for Nextstrain review.
- `examples/microbetrace-auspice-temporal-map.json`: compact synthetic Auspice v2 dataset for demonstrating map rendering and lossless `num_date` round trips.
- `examples/dated-newick/`: full-feature explicitly dated Newick bundle for testing `num_date`, time-tree, map, and metadata export together.
- `examples/auspice-export-input-types/`: full-feature Newick, FASTA, node-list, distance-matrix, and distance-link bundles with shared metadata, map, and style companions.
- `manual-test-data/auspice-export/README.md`: synthetic datasets and a requirement-by-requirement manual verification checklist for Auspice export.
