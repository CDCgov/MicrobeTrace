# View Testing Docs

Each view folder contains the Cypress-facing checklist, QA tracker, and bug log for that surface.

Typical files:

- `*-cypress-checklist.md`: maintained coverage target and notes.
- `*-cypress-qa-tracker.csv`: QA-facing tracker with status, fixture, and spec details.
- `*-cypress-bug-log.csv`: observed-vs-intended product bugs caught by Cypress.

The Table folder also contains `table-view-visual-regression-plan.md`.
