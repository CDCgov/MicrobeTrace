# Testing Docs

This folder contains the maintained Cypress testing documentation.

## Core Docs

- `test-runner-quick-reference.md`: targeted unit and Cypress run commands.
- `cypress-architecture.md`: maintained Cypress structure, selector rules, and migration guidance.
- `app-wide-cypress-bug-log.csv`: app-wide Cypress bug log for issues that span views or do not belong to one surface.
