Partner application proof of concept

This page is served from 127.0.0.1:4300, loads the real MicrobeTrace SDK from localhost:4200, and sends a user-approved dataset through the partner handoff.

Run locally

Terminal 1: npm start

Terminal 2: npm run demo:partner-embed

MicrobeTraceLoads #handoff and deletes the record.
